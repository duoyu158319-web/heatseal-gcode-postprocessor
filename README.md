# Heat-seal G-code postprocessor

本地运行的 Bambu Studio `.gcode.3mf` 后处理网页，用于在指定层加入暂停，并根据上一层识别出的闭合外墙生成无挤出热封复走路径。

主要功能：

- 分析层、主体 ID 与闭合外墙路径。
- 自动确定复走圈数，避免选择超过识别结果。
- 为每一圈独立设置相对速度，并以 `mm/s` 显示实际速度。
- 为每一圈独立设置 `0–0.5 mm` 外扩量，步长 `0.1 mm`，默认 `0.2 mm`。
- 使用圆角等距外偏，处理直线和 `G2/G3` 圆弧。
- 导出重新封装且更新 MD5 的 `.gcode.3mf` 文件。

## 本地运行

```powershell
node web/server.mjs
```

打开 `http://127.0.0.1:4173/`。

## 测试

```powershell
node --test web/core.test.mjs
```

## 安全提示

G-code 后处理涉及真实机械运动。导出前请检查暂停层、复走高度、速度、外扩方向和路径预览；首次运行新参数时应全程观察并准备停止打印。
