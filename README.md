# Heat-seal G-code postprocessor

本地运行的 Bambu Studio `.gcode.3mf` 后处理网页。它只在文件已有的 Bambu 暂停层之后，根据下方一层解析出的连续挤出轨迹生成无挤出热封路径，不会新增暂停。

主要功能：

- 只有包含 `M400 U1` 的 Bambu 已有暂停层可以选择，不默认选择最高层。
- 按 G-code 出现顺序列出暂停层下方一层的全部连续挤出打印线，包含开放线和闭合线。
- 在左中右仪表盘中同时查看轨迹、从画布或编号图例选择打印线，并调整当前线参数。
- 每条已选择打印线均可独立设置热封 1–3 遍。
- 每条打印线独立设置相对速度，并以 `mm/s` 显示实际速度。
- 暂停层热封沿原始打印线复走，不执行路径偏移。
- 最终切膜仍使用独立的圆角外扩算法，并支持直线和 `G2/G3` 圆弧。
- 导出重新封装且更新 MD5 的 `.gcode.3mf` 文件。

## 本地运行

```powershell
node web/server.mjs
```

打开 `http://127.0.0.1:4173/`。

## 测试

```powershell
node --test web/core.test.mjs
```

## 安全提示

G-code 后处理涉及真实机械运动。导出前请检查暂停层、选中的打印线、复走高度、速度和路径预览；首次运行新参数时应全程观察并准备停止打印。
